# Synchronized-high-density-electromyography-with-hand-wrist-and-forearm-kinematics

This repository contains synchronized high-density surface electromyography (HD-EMG) and three-dimensional kinematic data from the forearms of eighteen healthy subjects performing single degree-of-freedom upper-limb movements.
